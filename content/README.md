## 如何写笔记

打开 `content/` 中对应的 `.md` 文件，在现有标题和列表下直接添加文字、公式说明、代码块、图片或链接。保存并推送到 GitHub 后，网站会自动显示更新。

例如，在“数学基础”的 `## Calculus · 微积分` 下添加：

````markdown
### 梯度

梯度表示函数在各个变量方向上的偏导数组成的向量。

```python
def gradient(x, y):
    return (2 * x, 2 * y)
```
````

更详细的编辑步骤见仓库根目录的 `README.md`。
